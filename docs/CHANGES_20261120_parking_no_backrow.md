# 11/20 M4 주차: 뒷줄(4·5·6번) 확인 끔 (`fixed_backrow_mm` 620 → 0)

근거: 캡틴 규칙 확인 (11/20) — 4·5·6번(뒷줄)에는 빈칸이 없고, 목표는 항상 1·2·3번 중 하나.

## 바뀐 것
- 예전(11/19): 돌고 나서 앞범퍼 앞 50cm를 0.5초 확인(F_CHECK) → 물체 있으면 앞칸 완료, 없으면 뒷칸으로 62cm 더 직진(F_STR).
- 지금: 돌고 나면 바로 앞칸 완료 → 바퀴 펴고 5cm 후진(F_BPAUSE·F_BACK) → PARKED_FIXED.
- 좋아지는 점: 뒷줄 리모를 라이다가 놓치면 빈칸으로 잘못 보고 62cm 더 들어가던 위험이 사라지고, 확인하던 0.5초도 줄어듦.
- 코드는 지우지 않고 파라미터만 끔 (`fixed_backrow_mm: 0`). 규칙이 바뀌면 620으로 되돌리면 예전처럼 동작.
- 시험 중 되돌리기: `ros2 param set /parking_node fixed_backrow_mm 620.0` (주차 시작 전에 설정)

## 시험
- autorace_mission 424 통과 (새 5개: 기본값 0 / 1·2·3번 각각 확인 없이 앞칸 + 5cm 후진 / 앞이 비어 보여도 뒷칸으로 안 감.
  기존 뒷칸 시험 4개는 `fixed_backrow_mm=620`을 명시해 '켜면 예전처럼'을 확인)
- autorace_obstacle 106, limo_obstacle_avoid 185 통과
- 시뮬·실차 확인 전 (오프라인 시험만)
