# 11/14 수정 (1114_01 통주행 bag 분석 반영)

근거 bag: `1114_01_whitecone` (233초 통주행, 정적 장애물·라바콘·주차 = 종이컵/흰 컵, 신호등·주차 표지 = 휴대폰 화면).

## 1. M7 후진(온 길 되돌아가기) 다시 켬
- `avoid_params.yaml` `recover: true` (11/12 밤 `1bc4138`에서 끈 것).
- 순서는 그대로: 막히면 먼저 끝까지 꺾어 빠지기(`squeeze`) → 그래도 막혀 0.4 s 서 있으면 온 길 되돌아가기(`trail`, 최대 0.4 m × 3번) → 탈출(`swing`).
- 11/12에 끈 이유('옆에서 지나가는 장애물을 앞으로 세서 다음 장애물 앞에서 후진')는 그 뒤 `clear_rollout`으로 고쳐져 있음.
- stress_sim 280판: 끔/켬 둘 다 280/280, 결과 같음 (꺾기로 빠지는 배치라 되돌아가기가 안 생김). 막히는 배치는 `test_lane_fix_recover`에서 켜고 통과.

## 2. M2_EXIT 상태 추가 (갈림길 직후 ~ 라바콘 시작선)
- 순서: `... M7_OBSTACLE → M2_FORK → M2_EXIT → M8_CONES → ...`
- 시작: 섬 왼쪽 끝(`m2_island_end`, 새 도면 점) + `m2_exit_after_island_mm`(200). 도면 위치가 없으면 예전처럼 합류 끝/거리.
- 하는 일: 차선 인식 모드만 (`normal`, 양쪽 노란 선, 보통 차로 폭). 한쪽 선 모드(`left_only`/`right_only`)는 안 씀.
  좌하단 코너는 예전 M8 접근의 IMU 코너 미리보기(도면 곡률 R640을 `/route/preview`로) + 코너 지킴을 그대로 옮김. 코너 동안 0.15 m/s.
- 끝: 라바콘 시작선 (카메라 > 도면 > 거리, 또는 차로 안 콘이 가까움) → `M8_CONES`는 접근 없이 바로 `cones`.
- obstacle 노드는 M2_EXIT부터 콘을 미리 추적 (M2_EXIT → M8은 추적을 이어감). 명령(/obstacle/cmd_vel)은 M8에서만.
- `m2_exit: false`면 예전 동작 (M2 끝 → M8 접근에서 한쪽 선 모드). 연습 `set_state M8_CONES`도 예전 접근.
- 근거 (1114_01 영상을 차선 노드에 그대로 다시 넣음):

  | 구간 | 지금 (한쪽 선 모드) 선 없음 | normal (M2_EXIT) 선 없음 |
  |---|---|---|
  | 섬 끝 ~ 합류 끝 포함 M2 뒷부분 | 128 / 448 프레임 | 104 / 448 |
  | 좌하단 코너 (148~157초) | **161 / 276** (도면 곡률만으로 6초) | **0 / 276** |

  화면에 노란 선이 보이는데(디버그 회색) 한쪽 선 모드가 반대쪽 선이라 버렸던 것.

## 3. M1 신호등
- `stop_on_green_arrival: false`: 도착 때 초록이 확정돼 있으면 서지 않고 통과.
  빨강이거나 아무것도 못 봤으면 정지선(도면 위치 또는 카메라 횡단보도)에서 서서 **초록이 확정될 때까지** 기다림 (시간 제한 없음, 그대로).
- `mode_vote_need.M1_TRAFFIC` 7 → 4: YOLO가 약 2.5장/초(추론 343 ms)라 7장이면 초록 확정이 2.4초 늦었음 (1114_01: 처음 봄 209.4초 → 확정 211.8초).

## 4. 주차
- 실패해도 'parked' + 띠링이던 것: FSM은 `/parking/state`의 `result`를 보고 `PARKED...`일 때만 `parked (...)`, 아니면 `parking failed (FAIL_NO_CAR 등)`.
  `/mission/state`에 `parking_result`. 띠링은 성공일 때만 (실패면 chime_node 경고 로그).
- 1114_01 실패 원인: 칸에 종이컵 줄 → 라이다 덩어리가 컵 하나씩(25~50 mm)으로 끊겨 크기 거르기(150 mm)에 다 빠짐 → 짝 없음 → 3.5 m 직진 후 `FAIL_NO_CAR`. 코드 문제 아님 (상자로 바꿔 시험).
- **정중앙 맞추기 (`center_check: true`)**: 끝에서 양옆 물체 안쪽 면 가운데를 라이다로 재서 15 mm 넘게 벗어났으면 45 cm 빠졌다가 정중앙 선을 따라 다시 (2번까지).
  버그: 예전엔 `center_on_sides`일 때만 재서 `center_check`만 켜면 아무 일도 안 했음 → `center_check`만 켜도 잼.
  조건: 양옆 물체 안쪽 면이 앞바퀴 0~420 mm 띠에 둘 다 보이고 그 사이 650~1000 mm. 한쪽만 보이면 안 맞춤.
  시뮬레이션 (1·3·4·5·6 정차 → 2번):

  | 조건 | 끔 | 켬 |
  |---|---|---|
  | 기본 | +8 mm | +8 mm (15 mm 안이라 그대로) |
  | 회전반경 +4 cm | −32 mm | −13 mm |
  | 회전반경 −4 cm | +48 mm | −3 mm |
  | 라이다 위치 +5 cm | +34 mm | −2 mm |
  | 라이다 위치 −5 cm | −28 mm | −28 mm (끝에서 양옆이 띠에 안 잡힘) |

  다시 넣으면 약 10초 더 걸림.
