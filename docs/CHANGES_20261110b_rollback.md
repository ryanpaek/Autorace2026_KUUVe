# 11/10 실차 뒤 수정: 후진이 위치를 망가뜨림, 후진 3회 제한

## 1. 한 번 길을 잃으면 위치·모드가 다 뒤틀림 → 원인: 후진이 앞으로 간 거리로 쌓임
`mission_node._on_odom`이 거리를 이동 길이(hypot)로만 더했다. M7에서 막혀 1.5m씩 3번 후진하면
도면 위치가 실제보다 최대 9m 앞서고, 도면 선 짝짓기(순서대로 다음 선만 받음)도 다시 못 맞춘다.
- 시뮬레이션 (`tools/course_sim.py --scenario m7_rollback_old_unsigned`): M7 거리 초과로 강제 종료 →
  갈림길 A(틀림) → 라바콘 모드가 M7 구간에서 켜짐 → 신호등 정지선 6m 앞에서 정지
- 수정: odom 이동을 차 방향으로 투영해 뒤로 가면 거리에서 뺀다. 같은 상황에서 갈림길 B·신호등 −38mm·주차까지 정상
  (`--scenario m7_rollback_3x1.5m`)

## 2·3. 후진 거리 / 3회 뒤 멈춤 (limo_obstacle_avoid)
시뮬레이션에서 본 것: 1.5m 후진 → 갈 길 없음 → 같은 길로 전진 → **같은 자리에서 또 막힘** 반복. 횟수만 풀면 무한 반복.
- `recover_max` 3 → **0 (제한 없음)**. 값을 넣으면 예전처럼 그 횟수 뒤 정지
- 같은 자리(0.4m 안, 같은 차로)에서 또 막히면 최대 후진 거리를 1.0m씩 늘림 (1.5 → 2.5 → 3.5 …, 지나온 길 끝까지),
  "갈 길 찾음"으로 멈추기 전 최소 후진도 0.3m씩 늘림 → 매번 다른 곳에서 다시 고른다
- trail 모드에서 지나온 길이 없으면 예전 swing 후진을 하지 않고 서서 기다림
- `/avoid/state`에 `rollback_rep` (같은 자리 반복 횟수)
- 파라미터: `rollback_same_spot` 0.40, `rollback_grow` 1.00, `rollback_grow_min` 0.30

## 확인 안 된 것
- 실차 미검증. odom 부호는 /odom 자세(orientation)로 판단 — 리모 odom 방향이 차 방향과 맞는지 실차에서 후진 한 번 해 보고
  `/mission/state`의 `dist_mm`이 줄어드는지 확인할 것
- 시뮬레이션에서 막힌 배치는 모두 원래 지나갈 길이 없는 배치였다 (지나갈 수 있는 배치 280개는 후진 없이 통과).
  실차에서 막힌 원인(벽·잡음 장애물인지 진짜 배치인지)은 bag을 봐야 안다
- 4번 신호등 재학습은 데이터 일 (재승)
