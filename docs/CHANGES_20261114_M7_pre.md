# 11/14 M7 코너 미리보기 (코너 직후 2차선 장애물 → 1·3차선 미리 정하기)

## 문제
우하단 코너(R640, 90°)를 80° 돈 뒤에야 회피 노드를 켜고, 회피 노드는 라이다 지도가 쌓인 뒤(3번 확인)에야 2차선 장애물에 반응했다.
코너 직후 2차선에 정차 LIMO가 있으면 늦게 꺾어 서고 → 후진(온 길 되돌아가기) → 시간 손실.

## 바꾼 것
### `m7_link.py` — `CornerPreview` (모듈 설명 8)
- 코너를 20° 넘게 돈 뒤부터 라이다 점을 **3차선 직선 좌표**(시작선 x=0, 2차선 중심 y=0, 왼쪽 +)로 옮겨 쌓음.
  차 위치는 IMU로 돈 각 θ만으로 코너 중심선 모형에서 구함 (기준점 = (−288 − 640 cosθ, −640 + 640 sinθ), 방향 90° − θ). odom 안 씀.
- 2차선 장애물 앞면이 시작선 + 1.5 m 안이면 1·3차선을 같이 판단:
  - **빈 차로**: 2차선 장애물 앞면 + 0.6 m까지 그 차로에 장애물 없음 (2차선 장애물 옆·바로 뒤 확인)
  - **막다름**: 그 차로 다음 장애물 ±0.6 m에 2차선도 막힘 → 거기서 두 칸 건너야 함 → 피함
  - **꺾어 들어갈 수 있나**: 켤 자세에서 최소 회전반경 0.53 m·전방 주시 0.35 m로 굴려 보며 차 옆면이 2차선 장애물을 6 cm 넘게 비켜 가는지.
    코너 중간엔 차가 아직 **바깥(1차선) 쪽을 보고 있어** 안쪽 3차선은 코너보다 더 꺾어야 함 → 가까우면 1차선만 가능
  - 둘 다 되면: 더 많이 빈 쪽 → 비슷하면(0.3 m) 갈림길 방향 → 더 비켜 가는 쪽
- 켜는 각: 80°에서 켜서 비켜 갈 수 있으면 80° 그대로, 아니면 60~75° 중 비켜 갈 수 있는 **가장 늦은 각**.
- 켤 때 회피 노드에 `start_target`(+1/−1)·`start_y`(코너 모형 옆 위치)를 같이 넣음 (`obstacle_node._enable`).
- 로그 `[M7] 코너 미리보기 (코너 NN°): 2차선 300 mm 막힘 -> 1차선, ...`, `/obstacle/state`의 `m7_pre`, `m7_trigger: pre`.

### `avoid_core.py`
- `start_target`: 켜자마자 그 차로를 목표로. '다시 고르기'(앞이 더 빈 쪽으로 바꾸기)는 안 함 —
  시뮬레이션에서 다시 고르기가 못 꺾어 들어가는 3차선으로 바꿔 후진했음. 정한 차로가 정말 막히면 ①이 그대로 다시 고름.
- `start_y`: 켤 때 옆 위치. `start_heading_max_deg` 35 → 50.

## 시뮬레이션 `src/autorace_obstacle/test/m7_pre_sim.py`
첫 2차선 LIMO 앞면 = 시작선 +0~1.5 m인 무작위 7대 배치 40개, 진짜 M7Link·AvoidPlanner + `avoid_params.yaml` 값(후진 켬, 0.2 m/s).

- 남은 후진 2판: 2차선 LIMO가 시작선 +0.15~0.3 m이고 같은 줄 1차선도 막힘 → 3차선은 물리적으로 못 꺾어 들어감 (main도 후진).
- 코너 직후 2차선이 빈 배치 30개: 켬/끔 결과 완전히 같음 (미리 정하지 않음).
- 시작선 바로 앞 2차선 LIMO는 1차선으로, 60~75°에서 일찍 켬.

## 실차에서 볼 것
- 코너 중 로그 `코너 미리보기`의 2차선 거리가 실제 LIMO 위치와 맞는지 (모형 코너 R640·끝 −288 mm). 틀리면 `m7_pre_corner_r_mm`·`m7_pre_corner_end_mm`.
- 끄기: `m7_pre_enable: false` (예전과 같음).
