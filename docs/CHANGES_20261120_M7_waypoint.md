# 11/20 새벽 M7 웨이포인트 (m7_impl:=waypoint) 고침 — 가상 경기장 한 바퀴 기준

브랜치 `sim/overnight-1120` (main `c64162f`에서). **main 기본은 dash** → 이 노드를 쓰려면 `m7_impl:=waypoint`.
바뀐 파일: `limo_obstacle_avoid/m7_waypoint_core.py`, `m7_waypoint_sim.py`(오프라인 시뮬 옵션), `test/test_m7_waypoint_1120.py`.

## 찾은 문제 (가상 경기장 autorace_sim, 한 바퀴 M5→M4, 실차 1119_06 차량 설정)
1. **켤 때 옆 위치 오차 → Time-out.** 코너를 안쪽으로 붙어 돌아 실제로는 옆 −15~−21 cm, 방향 +15~+18°로 켜지는데
   노드는 옆 0(·+10°)으로 시작. 기존 보정(LIMO 차로 격자 스냅)은 15 cm까지라 못 고침 → 옆 오차 25~55 cm(한 차로)로 커짐 →
   LIMO가 차로 경계에 걸쳐 보여 '길 없음'·'굴려 보니 닿음' 반복 → 15 s Time-out (기준 판 M7 2.9/10, 이어서 M2·M8 순간이동 연쇄).
2. **끝 처리.** `section_length - end_before`에서 무조건 끝. 실차는 m7_link가 섬 거리를 4.8 m로 자르므로(11/18 로그 '섬까지 4.80 m')
   마지막 줄 LIMO 전에 FSM에 넘기고 FSM은 그 차로로 직진할 수 있음. 갈림길 표지를 늦게 알아도 반영 못 함.
3. **15 s 규정.** '기다림'과 '굴려 보니 닿음 -> 정지'가 번갈아 나오면 기다림 타이머가 0으로 돌아가 끝없이 섬.
   앞이 creep_stop(30 cm) 안이면 천천히 가기도 안 돼 영원히 섬 (reverse_max 0).

## 고친 것 (모두 파라미터로 끌 수 있음)

## 시뮬 주의 (실차와 다름)
- 시뮬 섬 앞 끝이 시작선에서 4.35 m → 1차 배치 마지막 줄(4.41/4.42)이 갈래 입구를 막음. 실차는 섬 앞이라고 함 → 시뮬은 5대로, 마지막 줄은 오프라인으로.
- 시뮬 표지는 3.27 m LIMO에 가려 M7 끝까지 못 보는 경우가 많음 → M2가 회피 끝 차로 따라 50% 틀림 (코드 문제 아님 추정).
- M2 출구(섬 끝 합류) A·B 모두 차선 노드 island_ref가 바깥선을 섬 변으로 잡아 바깥으로 꺾임 → M8 미진입. **dash도 같음.** 실차 확인 필요.
- M1/M3: 카메라 정지선 거리는 실제와 5 mm 안. FSM이 stop_target 150/250 mm 앞에 서게 맞춰져 있고(11/15 실차) 시뮬 차는 3 cm만 밀려 13~27 cm 앞에 섬.

## 실차에서 볼 것
- `ros2 topic echo /avoid/state` 의 `yfix_cm`: 코너 뒤 첫 1~2 m에 몇 cm 고치는지. 노란선을 잘못 봐 튀면 `yellow_fix: false`.
- 끝: 로그 `끝 거리 지났지만 계속` / `3차선 끝 -> 차로 N로 끝 (출구 A/B)` 위치가 섬 앞인지.
- `15 s 막기` 로그가 나오면 그 앞 상황(길 없음/굴려 보기) 확인.
