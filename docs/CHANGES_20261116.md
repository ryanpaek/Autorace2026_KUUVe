# 11/16 수정 (1116_01 실차 주행 분석 반영)

## 1. M7 정적 장애물: 내 차로 위치 바로잡기 + 조향 더 적극
- 원인: 카메라는 3차선(선 종류로 lane_id −1)인데 회피 노드 위치는 y≈−0.30 m(2·3차선 사이)로 남음.
  `_lane_id_fix`는 "다른 차로일 때만" 고쳐서 같은 차로 안의 치우침은 안 고침 → 노란 선 막기와 약 50초 왔다갔다.
- 고침: 같은 차로라도 목표 차로 = 카메라 차로이고 방향이 반듯하면, 차로 중심 + 차선 오프셋과 0.08 m 넘게 다르면 그 차이의 50%만큼 위치를 옮김
  (`lane_id_inlane`, `_tol` 0.08, `_gain` 0.5).
- `lookahead` 0.35→0.30, `outer_entry_lookahead` 0.55→0.45 (더 일찍·더 많이 꺾음).

## 2. 갈림길 표지 뒤 ~ 라바콘 전: 차선 우선
- 원인: 갈래 안에서 `left_only` 한쪽 선만 보는 모드 → 차선 없음(NONE) 48%, 합류 곡선 76%.
  같은 영상을 normal 모드로 다시 돌리면 13%, 14%.
- 고침: 섬 끝을 300 mm 지나면 normal 모드(위치 모르면 갈래 들어와 700 mm).
  합류 S자(`m2_merge`)도 차선이 잡히면 차선으로 주행, 5프레임 연속 놓칠 때만 정해진 방향 주행.
- 바닥 A/B: 차선 노드가 이미 읽음(`floor_letter`). 다만 출발·지그재그에서 잘못 읽은 'A'도 있어 판단 근거로는 안 씀.

## 3. 라바콘 직후 곡선: 차선 우선
- 원인: M8 뒤 `m1_force_corner`(IMU로 정해진 원호)를 차선이 100% 보이는데도 씀.
- 고침: `_m1_forced`도 같은 `lane_first` 규칙(차선 잡히면 차선, 5프레임 놓치면 정해진 원호).

## 4. 주차
- 가운데 마진: `center_tol_mm` 15→50 (칸 기준 약 ±20%). 50 mm 안이면 다시 안 맞춤.
- 다시 맞출 때 후진: `center_pullout_mm` 450→320, 오차 비례 추가 0(`center_pullout_per_mm` 0). `center_look_mm` 180→130.
- 다시 들어갈 때(TURN 직진 구간): 오른쪽 고정이 아니라 칸 선 방향에 맞춰 좌우로 조향(`_align_kappa`, gain 3.0, 최대 곡률 1.5).
- 반경 `arc_radius_mm` 640→590 (1116 실차), 도는 중 바로잡기 문턱 35→50 mm·70%만 고침.
- 시뮬(반경 590~720, 서보 지연 0~120 mm): center_check 켬 최악 39 mm(다시 맞춤 2회까지), 끔 최악 77 mm.

## 5. 연산량 측정 (`sys_monitor`, 새 노드)

- 녹화 목록에 `/system/usage` 추가 (RUN_GUIDE).
