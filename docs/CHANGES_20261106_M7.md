# 변경 내역 (2026-11-06): M7 3차선 정차 LIMO 회피 연결

브랜치 `claude/blissful-bardeen-ovgg6s` (기준: `main` b042b3a). 명령어는 [src/limo_obstacle_avoid/COMMANDS.md](../src/limo_obstacle_avoid/COMMANDS.md).

## 한 줄 요약

윤서의 회피 패키지 `limo_obstacle_avoid` v0.2를 레포에 넣고, 팀 미션 FSM이 **3차선 시작선에서 켜고 회피가 끝나면 넘겨받도록** 연결했다.
`ros2 launch autorace_bringup autorace.launch.py m7_avoid:=true`로 켠다. 기본값(`m7_avoid:=false`)이면 예전과 똑같이 동작한다.

## 구조

```
mission_node ──/mission/state──▶ obstacle_node (m7_link.py)
   ▲                               │ M7 + 앞바퀴가 3차선 시작선 → section_length 설정 후 /avoid/enable
   │                               │ fork_choice → /fork_direction
   │                               │ /avoid/active·done → /obstacle/state의 m7_active·m7_done·m7_exit
   └──/obstacle/cmd_vel ◀── avoid_node (/avoid/cmd_vel 을 remap)
/cmd_vel은 계속 mission_node 하나만 낸다 (비상정지 /mission/estop 그대로 동작)
```

## 실차 전에 남은 것

1. **3차선 한 칸 폭 실측**: 회피 `lane_width` 0.55와 FSM `three_lane_width_mm` 500을 같은 값으로.
   (0.50인데 0.55면 바깥 차로 중심을 5 cm 바깥으로 잡음. 정렬 보정은 폭 비율 오차를 못 고침)
2. **브리지 축거**: `autorace.launch.py`의 브리지는 `wheelbase`를 안 넘겨 0.2로 돈다 (유효값 0.222).
   조향각 = atan(축거 × angular.z / v)라서 작은 축거로 계산하면 **덜 꺾여** 회전 반경이 약 11% 커진다 (11/07 표현 정정).
   차선 주행에도 영향이 있어 이번엔 안 고침 → `drive_test steer`로 실제/기대 비율을 재고 팀 결정.
3. **실차 순서**: 단독 ②~⑦ (`COMMANDS.md` 3번) → `m7_avoid:=true m7_dry_run:=true` → `m7_avoid:=true`.
4. **팀 결정**: 표지를 끝까지 못 읽었을 때 갈림길 — 지금은 회피 노드가 고른 차로를 M2가 따름 (`m7_fork_fallback: auto`, `fork_from_m7_exit: true`).

## 추가 (11/07): 회피 노드가 도중에 멈출 때 정지 (`m7_hold`)

윤서 검토로 찾은 안전 구멍. v0.2 단독 시험은 `cmd_mux`의 `failsafe_hold`가 막지만, 팀 스택은 `cmd_mux`를 안 써서 빠져 있었다.

| 상황 | 고치기 전 | 고친 뒤 |
| --- | --- | --- |
| 회피 노드 Ctrl+C (active=false, done 없음) | `m7_active` false → 차선 주행으로 정차 LIMO 사이 직진 | 즉시 정지 (`m7_hold`) |
| 회피 노드가 그냥 죽음 | `m7_active`가 true로 남음 → `mission_node` 0.3 s 타임아웃에만 의존 | `/avoid/active` 0.5 s 끊기면 정지 |
| 정상 종료 (active=false 직후 done) | M2로 | 그대로 M2로 (정지 안 함) |
| dry_run (active를 안 냄) | 차선 주행 | 그대로 (제어를 잡은 적이 없으니 정지 안 함) |

바뀐 파일: `m7_link.py`(`m7_hold`), `fsm.py`(hold면 `stop`), `obstacle_node.py`(`/avoid/active`에 시각), 테스트 6개 추가 (`test_m7_link.py` 5, `test_fsm_route.py` 1).
정지를 풀려면 `/mission/set_state`로 `WAIT_START`를 보낸 뒤 다시 `M7_OBSTACLE` (M7에서 곧바로 M7을 다시 보내면 안 풀림). 시험 6개 추가로 전체 108 passed.

검토에서 함께 정리한 것:
- 단독 시험(s4~s6)용 브리지와 `s6_avoid_run`(`cmd_mux`)은 팀 스택을 켜기 전에 끈다 (브리지·`/cmd_vel` 발행자 중복).
- `section_length`는 앞바퀴 기준, 회피 노드 원점은 차 기준점이라 섬을 앞바퀴~기준점 거리만큼 가깝게 본다 → 조금 일찍 빠지는 안전한 쪽 오차라 그대로 둠.

## 추가 (11/09): M7 켜기·끄기 방식 변경

실차 문제: ① 시작선 기준 켜기가 약 50 cm 늦게 켜짐, ② 끄는 위치가 들쭉날쭉 (회피 노드가 자기 오도메트리로 섬 끝 + 30 cm를 판단, 안 되면 FSM이 섬 끝 + 50 cm 강제).

| | 새 방식 (`params.yaml`, 기본 켜짐) | 안전장치 | 옛 방식으로 |
| --- | --- | --- | --- |
| 켜기 `m7_enable_mode: obstacle` | 횡단보도를 벗어나면(M7 진입) 라이다로 앞 차로(차 중심 ±200 mm) 감시 → 장애물이 **라이다 앞 1.0 m** 안이면 켬 | 시작선 −25 cm부터만(코너 안 오검출 방지), 끝까지 없으면 시작선 + 1.0 m에서 켬 | `line` |
| 끄기 `m7_off_mode: sign` | YOLO 갈림길 표지(fork_a/fork_b)를 5프레임 중 3번 보면 '확인' → 5프레임 연속 안 보이면 '지나감' → 끔 | 섬 앞 1.5 m 안 + 바깥 차로(A/B)일 때만. 회피 노드 자체 종료·FSM 강제 종료는 그대로 예비 | `none` |

켜는 거리를 제안값 0.7 m가 아니라 1.0 m로 정한 이유 (회피 시뮬레이션, 가운데 장애물 1대, 오차 조건 7개):
0.7 m는 3/7만 성공(출발 방향 +3°·옆 6 cm·복합에서 장애물 앞에 멈춤, −5°에서 차선 이탈 8.8 cm), 0.85 m는 −5°에서 이탈 6.5 cm,
0.9 m 이상부터 멈춤 없음 (0.9: 18/21, 1.0: 19/21, 1.1: 19/21). 1.0 m는 회피 노드의 차로 변경 시작 거리(trigger_dist)와 같다.
남는 실패(−5° 출발 방향에서 2 cm 넘는 이탈)는 조향 다듬기(2-6) 몫.

새 상태값 (`/obstacle/state`): `m7_trigger`(obstacle/fallback/line), `m7_front_mm`(라이다 앞 거리), `m7_sign`(lostN/near), `m7_off_by`(sign/avoid_done).
실차에서 정할 것: `m7_off_sign_near_h_px`(표지가 가까울 때 상자 높이, 지금 0 = 안 씀), 표지 실제 위치에 따라 `m7_off_gate_mm`.

## 추가 (11/09 오후): 카메라 차선 보정, 멈춤 탈출, M7 종료 차로 토픽

**① 회피 중 차로 기준 = 팀 차선 인식 결과 (`lane_fix`)**
회피 노드는 원래 카메라를 안 쓰고, 켤 때 위치를 가운데 차로 중앙으로 놓은 뒤 odom 거리 + IMU 방향으로만 옆 위치를 계산했다
(정차 LIMO로 조금 보정). 켤 때 어긋나 있으면 끝까지 그 오차를 안고 감.
이제 팀 `lane_node`의 `/lane/status`(offset_mm, heading_rad)를 그대로 받아 옆 위치·방향을 맞춘다. 차선 코드를 복사하지 않으므로
차선 주행과 항상 같은 기준이고, 차선 코드가 고쳐지면 자동으로 따라감.
안 쓰는 경우: 한쪽 선만 보임, 신뢰 낮음(low_conf), 차선 방향 10° 초과(차로 변경 중·3차선 입구 사선), 지금 추정과 15 cm 넘게 다름(다른 차로).

**② 멈춤 탈출 (`recover`)**
예전: 앞 비상(범퍼 앞 25 cm, 차폭 안) 또는 갈 차로가 막히면 속도 0 → 차가 안 움직이니 상황도 안 바뀌어 계속 정지.
이제: 0.8초 계속 막히면 0.25 m 후진하며 크게 꺾어(최소 회전반경) 머리를 갈 차로 쪽으로 돌린 뒤 다시 계획. 최대 3번, 넘으면 예전처럼 정지.
차로를 옮기던 중이면 가던 차로 쪽으로 돌림 (처음 구현은 반대로 돌려 같은 자리에서 다시 막혔음 → 수정).
시뮬레이션 (가운데 장애물, 오차 조건 7 × 3): 라이다 앞 0.6 m에서 켬 3/21 → 18/21, 0.7 m 12/21 → 18/21, 멈춘 채 끝 21건 → 0건.
무작위 배치 140/140, 기존 배치 20/20 그대로. 시뮬레이터가 후진을 앞으로 계산하던 것도 고침(forward 인자).

**③ M7 종료 차로 토픽 `/m7/exit_lane` (latched)**
M7이 끝나는 순간(회피 노드 종료 / 표지로 끔 / FSM 강제) 한 번 발행:
`{"lane": 1|2|3, "fork": "A"|"B"|null, "side": "왼쪽|가운데|오른쪽", "avoid_lane": +1|0|-1, "by": "avoid_done|sign|forced", "text"}`.
1차선 = 왼쪽 = A, 3차선 = 오른쪽 = B. 늦게 켠 노드도 마지막 값을 받음.

**조향(4번)**: 이번엔 값을 안 바꿈. 카메라 차선 보정으로 옆 위치 오차가 줄어든 상태에서 실차 `/avoid/state`(lane_fix_dy_cm, y)를 보고 lookahead 등을 정할 것.
