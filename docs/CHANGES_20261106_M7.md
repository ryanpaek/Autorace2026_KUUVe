# 변경 내역 (2026-11-06): M7 3차선 정차 LIMO 회피 연결

브랜치 `claude/blissful-bardeen-ovgg6s` (기준: `main` b042b3a). 명령어는 [src/limo_obstacle_avoid/COMMANDS.md](../src/limo_obstacle_avoid/COMMANDS.md).

## 한 줄 요약

윤서의 회피 패키지 `limo_obstacle_avoid` v0.2를 레포에 넣고, 팀 미션 FSM이 **3차선 시작선에서 켜고 회피가 끝나면 넘겨받도록** 연결했다.
`ros2 launch autorace_bringup autorace.launch.py m7_avoid:=true`로 켠다. 기본값(`m7_avoid:=false`)이면 예전과 똑같이 동작한다.

## 구조

```
mission_node ──/mission/state──▶ obstacle_node (m7_link.py)
   ▲                               │ M7 + 앞바퀴가 3차선 시작선 → section_length 설정 후 /avoid/enable
   │                               │ fork_choice → /fork_direction
   │                               │ /avoid/active·done → /obstacle/state의 m7_active·m7_done·m7_exit
   └──/obstacle/cmd_vel ◀── avoid_node (/avoid/cmd_vel 을 remap)
/cmd_vel은 계속 mission_node 하나만 낸다 (비상정지 /mission/estop 그대로 동작)
```

## 해결한 문제

| # | 문제 (넣기만 했을 때) | 해결 | 근거 (계산·확인) |
| --- | --- | --- | --- |
| ① | 패키지의 `cmd_mux`와 `mission_node`가 둘 다 `/cmd_vel` 발행. `cmd_mux`는 차선 명령을 못 받아 0을 초당 30번 섞음, 비상정지 우회 | 본 주행에선 `cmd_mux`를 안 켜고 `avoid_node` 출력을 `/obstacle/cmd_vel`로 remap | 팀 `lane_node`는 `/lane/cmd_vel`로 내고, 패키지는 `/lane_follow/cmd_vel`을 기다림 |
| ② | 기존 `obstacle_node`가 `/obstacle/cmd_vel`에 0을 계속 냄 | M8 라바콘에서만 발행 | 회피 노드와 같은 토픽을 나눠 씀 |
| ③ | FSM은 횡단보도를 벗어나자마자 M7 → 그때 켜면 원점이 코너 전 | 앞바퀴가 시작선에 닿을 때 켬: 카메라 흰 선 + 오도메트리 → 도면 위치 s → M7 진입 후 거리. 차선 방향 3° 초과면 최대 30 cm 미룸 | M7 진입(s=11905) ~ 시작선(s=13589) 1.68 m, 사이에 90° 코너. 방향 3° 오차 = 4.38 m 뒤 옆 23 cm |
| ③' | 늦게 켜지면 섬까지 거리가 달라짐 | 켜기 직전 `section_length` = 섬 끝 − 지금 위치 (파라미터 서비스) | 시작선 ~ 섬 끝 도면 4384 mm |
| ④ | FSM은 섬 끝 30 cm 앞에서 M2로, 회피는 섬 끝 30 cm 뒤에 끝남 | M7은 `m7_done`으로 종료. 안 오면 섬 끝 + 50 cm에서 강제 종료 + 회피 노드 끔 | 0.6 m, 0.25 m/s로 2.4초 먼저 제어를 뺏김 |
| ⑤ | 갈림길 방향 전달 없음 | FSM 투표 → `/fork_direction`. 끝까지 못 읽으면 M2가 회피가 끝난 차로 사용 | A = 왼쪽 = +1 규약 양쪽 동일 확인 |
| ⑥ | 회피 노드가 켜지기 전(코너 구간)에도 obstacle 명령을 쓰면 정지 | 회피 노드가 실행 중(`m7_active`)일 때만 obstacle, 그 전엔 차선 | |

## 시험으로 바꾼 판단

- `side_margin` 0.05/0.08/0.10: 140건 결과·최소 간격 동일 → 차로 판단에만 쓰이고 지나가는 간격엔 영향 없음. 기본값 유지.
- `clear_back` 0.05/0.10/0.15: 성공 140/133/127, 최소 간격 4.6/7.9/5.3 cm → 오히려 나빠짐. 기본값 0.0 유지.
- M7만 연습할 때 `start_state:=M7_OBSTACLE`은 도면 위치를 안 맞춰 회피가 약 1.4 m 늦게 켜짐 → `/mission/set_state`로 할 것 (COMMANDS.md에 반영).

## 실차 전에 남은 것

1. **3차선 한 칸 폭 실측**: 회피 `lane_width` 0.55와 FSM `three_lane_width_mm` 500을 같은 값으로.
   (0.50인데 0.55면 바깥 차로 중심을 5 cm 바깥으로 잡음. 정렬 보정은 폭 비율 오차를 못 고침)
2. **브리지 축거**: `autorace.launch.py`의 브리지는 `wheelbase`를 안 넘겨 0.2로 돈다 (유효값 0.222).
   회피 회전이 약 11% 커짐. 차선 주행에도 영향이 있어 이번엔 안 고침 → 팀 결정 필요.
3. **실차 순서**: 단독 ②~⑦ (`COMMANDS.md` 3번) → `m7_avoid:=true m7_dry_run:=true` → `m7_avoid:=true`.
4. **팀 결정**: 표지를 끝까지 못 읽었을 때 갈림길 — 지금은 회피 노드가 고른 차로를 M2가 따름 (`m7_fork_fallback: auto`, `fork_from_m7_exit: true`).
