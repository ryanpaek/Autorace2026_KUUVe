# 11/09 미션 켜기·끄기 트리거 정리 (feat/mission-triggers)

원칙: 표지판·흰 선(카메라)이 1순위, 도면 위치(odom)가 2순위, 거리는 마지막 안전장치. 로그에 `FALLBACK:`이 찍히면 2·3순위로 넘어간 것.

| 미션 | 켜짐 | 꺼짐 | 담당 |
|---|---|---|---|
| M5 서행 | 서행 또는 방지턱 표지 하나 (`slow`/`bump` 투표) | IMU 기울기 속도 ≥ `bump_imu_rate`(0.3) 뒤 `bump_after_mm`(300) / 예비: `bump_slow_mm` | 이번 수정 |
| M6 지그재그 | 시작 흰 선을 앞바퀴가 지나는 순간 서행 | 횡단보도 정지 후 재출발 (M3 정지 전까지 서행 유지) | 이번 수정 |
| M3 횡단보도 | 보행자 표지 또는 정지선 근처 → 정지선 정지 | 3.5초 대기 후 일반 속도로 출발 | 그대로 |
| M7 장애물 | (유빈) | (유빈) | 유빈 |
| M2 갈림길 | 방향 표지 A/B | 합류 지점(도면 `m2_merge_end`)에서 일반 차선 | 그대로 |
| M8 라바콘 | 시작 흰 선을 앞바퀴가 지나는 순간 (서지 않음) | 앞 800mm·구간 폭 안 콘 0개가 0.5초 (콘을 본 뒤, 500mm 이상 간 뒤) / 예비: 끝선, `cones_done`, 최대 거리 | 이번 수정 |
| M1 신호등 | (재승) | (재승) | 재승 |
| M4 주차 | 주차 표지 봄(명령 경로는 M4에서, 원시 검출 경로는 M1부터) → 주차 노드가 앞 선을 받음 / 예비: 도면상 앞 선 800mm 앞 | 주차 완료. 앞 선까지 서행 0.2, 서지 않음 | 이번 수정 |

공통: 서행 속도 0.2 (`slow_speed`). odom이 한 틱에 600mm 넘게 튀면 무시 (PR #19 포함).

## 새 토픽 값
- `/mission/state`: `parking_sign`, `parking_armed`
- `/obstacle/state`: `cone_any_ahead_mm` (앞바퀴 앞, 구간 반폭 650mm 안 가장 가까운 콘. 양쪽 통로라 차 앞을 안 막는 콘도 셈)

## 실차에서 확인할 것 (미검증)
1. 방지턱: bag에 방지턱 통과가 없어 `bump_imu_rate` 0.3은 추정. 방지턱 위로 손으로 밀어 보며
   `ros2 topic echo /imu --field angular_velocity`의 x·y가 얼마나 튀는지 보고 조정. 로그 `M5 bump felt`.
2. 지그재그·라바콘 시작선: `/mission/state` note와 로그 `start line (camera)` / `(route/distance)`.
3. 라바콘 끝: 로그 `no cones ahead`. 콘(종이컵)이 라이다 높이에 걸려야 함.
4. 주차: `/mission/state`의 `parking_armed`가 앞 선 전에 true가 되는지.

## 11/10: #23(YOLO 명령 발행) 위에 맞춤
- 명령 경로(`use_class_commands:=true`, 기본)에서도 예비 경로 유지: M5는 표지를 놓치면 도면상 서행 선에서 서행,
  M4는 P 표지 명령이 없어도 도면상 주차 앞 선 800mm 앞부터 주차 노드로 넘김. 넘기기 전에는 차선 주행(서행 0.2).
- 경로 지도가 없을 때: 명령 경로는 P 표지 명령이 있어야만 주차 시작.
