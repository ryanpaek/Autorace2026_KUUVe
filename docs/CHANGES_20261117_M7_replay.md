# 11/17 M7 전면 수정: 녹화한 차로 변경 동작 재생

## 무엇이 바뀌나
- **그대로**: 횡단보도 → M7 직전 우하단 코너(차선 주행 + IMU 코너 지킴) → 3차선 시작선 근처에서 켜기(m7_link),
  갈림길 방향 전달(/fork_direction), 끝나면 FSM M2로 (m7_done, m7_exit). FSM 코드는 안 바꿈.
- **새로**: 켜진 뒤부터 섬 끝까지를 `limo_obstacle_avoid/m7_replay_node`(launch 이름 `avoid_node`)가 맡음.
  예전 avoid_node와 토픽이 같아 m7_link·mission_node는 그대로 동작.
- 예전 방식으로 돌리기: `ros2 launch autorace_bringup full.launch.py m7_impl:=legacy`
- 재생 방식일 때 obstacle_node 설정 두 개를 launch에서 바꿈: `m7_pre_enable false`(코너 중간에 켜지 않음),
  `m7_off_mode none`(표지 보고 중간에 끄지 않음. 재생 노드가 끝냄)

## 구조 (m7_replay_core.py)
좌표: 켜는 점 원점, x = 차로 방향, y = 왼쪽 +. 차로 +1 = 1차선(A, 왼쪽) / 0 = 2차선 / -1 = 3차선(B).
차로 중심 간격 0.52 m(도면: 차로 500 + 선 20). 섬 앞 끝 = 켜는 점 + section_length(m7_link가 넣음, 도면 4.384 m).
섬은 바닥 선이라 라이다에 안 보임 → 도면 위치로 가상 장애물.

위치 = odom 이동 거리 + IMU 방향 (녹화 도구와 같은 계산) + 카메라 양쪽 선으로 옆 위치·방향 보정 +
차선 노드 lane_id(선 종류로 본 차로 번호)가 5/7번 같으면 차로 번호 고침 → **늘 몇 차선인지 앎**.

### 우선순위 (위가 먼저)
1. 안전: 센서 끊김 / 진행 방향 차체 바로 앞·뒤(재생 중 1.5 cm, 평소 4 cm + 제동 거리)에 라이다 점 → 정지.
   재생 중 2초 넘게 막히면 재생을 그만두고 그 자리에서 다시 판단
2. 섬: 가운데 차로로 섬 앞 끝에 닿기 전이면 정지 (옮길 수 있을 때까지)
3. 정한 동작 끝까지: 재생(EXEC)·정렬(ALIGN) 중엔 새 판단 안 함
4. 앞 장애물: 지금 차로 라이다 거리 ≤ `trigger_mm`(546) + 속도×지연(0.15 s) (+ 서야 하면 제동 0.13×속도)
   → 차로 고르기 → (정렬) → 재생
5. 출구: 섬 앞 끝 − 동작 길이 − 0.3 m부터, 가운데 차로면 출구 쪽(안 되면 반대쪽) 바깥 차로로.
   반대쪽 바깥 차로면 두 칸 거리 전부터 가운데로 한 칸
6. 끝: 섬 앞 끝 + 0.3 m를 바깥 차로로 지나면 DONE (끝 차로 → m7_exit → FSM이 그 갈래)
7. 평소: 지금 차로 중심 따라 0.2 m/s

### 차로 고르기
옆 차로 후보마다 **녹화 경로를 그 자리에 붙여 굴려 봄**: 차체 + 3 cm 안에 라이다 점(또는 섬)이 들어오면 못 감.
- 하나만 되면 그쪽 (= 답이 정해진 경우, 두 차로가 막힌 경우 남는 차로)
- 둘 다 되면 출구(A/B) 쪽, 출구를 모르면 더 멀리 빈 쪽
- 둘 다 안 되면 정지 3초 → 0.35 m 물러나 다시 봄(한 번) → 그래도 안 되면 정지 유지

### 정렬 (가장 가까운 두 선 사이 가운데로)
재생 전: 옆 3 cm / 방향 3° 밖이거나 녹화 시작 거리보다 5 cm 넘게 가까우면 서서,
차로 중심선을 따라 0.35 m 후진 → '장애물까지 546 mm 지점'까지 전진 (게인 큼, 0.15 m/s), 최대 3번.
허용 오차 안이면 서지 않고 바로 재생(지연 없음). 재생 뒤: 같은 방식으로 제자리(같은 x) 맞춤.

### 재생
녹화 경로를 '장애물 앞 546 mm 지점(라이다 기준), 지금 차로 중심, 차로 방향'에 붙여 path_follower와 같은 식으로 따라감
(기록 곡률 미리 + 옆·방향 오차). 녹화 끝 옆 위치가 0.52가 아니어도 0.8~1.25배 안이면 0.52에 맞게 늘림.
전진/후진 구간 그대로. 녹화 파일: `src/limo_obstacle_avoid/paths/m7_left.csv`, `m7_right.csv`
(한쪽만 있으면 거울상, 둘 다 없으면 기본 S자 1.3 m).

## 시뮬레이션 (`python3 src/limo_obstacle_avoid/tools/m7_replay_sim.py`)
조향 지연 0.25 s, 실제 회전 90%, odom 방향 +12%, 켤 때 옆 ±3 cm·방향 ±3°, 카메라 잡음. 7배치 × 출구 A/B × 2 seed:
**28/28 부딪힘·섬 침범 없이 끝**, 최소 간격 7.4 cm, M7 27~39 초. 출구 차로 22/28 (나머지 6은 출구 쪽이 섬 바로 앞에 막힌 배치 → 반대쪽 바깥 차로로 끝).
※ 모형 녹화(최대 조향 S자)는 546 mm에서 시작하면 모서리에 닿아 시뮬레이션만 700 mm. 실제 녹화로 돌리기: `--left m7_left.csv --right m7_right.csv`

## 실차 확인
```bash
ros2 launch autorace_bringup full.launch.py             # 기본 m7_impl:=replay
ros2 topic echo /avoid/state     # phase(CRUISE/STOP/ALIGN/EXEC), now_lane, target, gaps_mm(차로별 라이다 거리), why
```
로그 `[M7 재생]`: 시작할 때 어떤 녹화 파일을 쓰는지, 차로 선택 이유, 정렬 전후 오차, 재생 끝 오차.
M7만 연습: `/mission/set_state M7_OBSTACLE` (차를 3차선 시작선 30 cm 앞에).
조정: `ros2 param set /avoid_node trigger_mm 560.0`, `latency_s`, `align_before false`(정렬 끄기) 등 (config/m7_replay_params.yaml).

## 11/17 저녁: M2 갈림길도 녹화 재생 (M7 재생 노드가 이어서)
- M7 재생 노드가 **M7 끝 지점**(앞범퍼가 섬 앞 꼭짓점 `m2_start_gap` 1.0 m 전)에 오면, 지금 차로(1·2·3)와 A/B
  (`/fork_direction`, 못 봤으면 `m2_fork_default` A)로 `paths/m2_{차로}-{A|B}.csv` 하나를 재생 → 갈래 안에서 끝(m7_done).
  끝 차로를 A면 1차선, B면 3차선으로 넘겨(m7_exit) FSM M2가 그 갈래 차선 주행을 이어 감 (섬 지나면 양쪽 선 보통 모드).
- 차로 번호: 1 = 1차선(진행 방향 왼쪽, A 쪽) / 2 = 가운데 / 3 = 3차선(오른쪽, B 쪽). `/avoid/state`의 now_lane_no.
- M2 녹화를 쓸 수 있는 차로면 예전 '섬 앞 바깥 차로로 옮기기'는 안 함 (차로 그대로 M7 끝 지점까지).
- M2 녹화 길에 장애물(라이다)이 있으면 장애물 회피 먼저, 시작 지점 + 0.4 m까지 늦어지면 그 자리에서 M2 시작, 그보다 늦으면 예전 방식.
- 없는 파일은 좌우 대칭 파일 거울상(1-A↔3-B, 1-B↔3-A, 2-A↔2-B). 시작 로그 `[M2 재생] N/6개`.
- M2 재생이 섬 지나서까지 M7 안에서 돌므로 FSM `m7_force_after_island_mm` 500 → 1500.

### M2 녹화 방법
1. 차를 그 차로 **가운데에 반듯이**, **앞범퍼가 섬 앞 꼭짓점(가운데 차로가 갈라지기 시작하는 점)에서 1.0 m 앞**에 놓는다.
   다른 거리로 녹화했으면 `m2_start_gap`을 그 값으로.
2. `python3 path_recorder.py m2_1-A.csv` … 갈래 안으로 들어가 **차선 주행이 바로 이어받을 수 있게 갈래 차로 가운데·반듯이**에서 멈춘다.
3. `paths/`에 복사 후 빌드. `python3 path_check.py m2_1-A.csv`로 모양 확인.

## 11/17 밤: 너무 가까우면 후진 후 재시도, 차로 기억, M2만 시험
- **차로 기억**: 재생이 끝까지 가야(Track 끝) 목표 차로로 셈. 재생 중 2초 넘게 막혀 그만두거나 경로에서 벗어나면 그때 위치(odom+IMU,
  카메라 보정)로 가장 가까운 차로. 평소엔 옆 위치가 차로 중심에서 0.6칸 넘게 벗어나면 그 차로로, 카메라 lane_id 7번 중 5번이면 그 차로로.
- **후진 재시도** (`backup_if_mm` 350): 지금 차로 앞 장애물이 350 mm보다 가까우면 차로 중심선을 따라 후진(카메라로 고친 옆 위치·방향을
  맞추며, 0.12 m/s, 최대 0.6 m) → `backup_to_mm`(0 = trigger_mm 540)까지 → 다시 판단(빈 차로면 녹화 재생).
  540까지 가는 이유: 녹화 경로는 장애물 앞 540 mm에서 시작하는 모양이라 350에서 시작하면 앞부분을 건너뛰고 급하게 꺾음.
- **M2만 시험**: `ros2 param set /avoid_node m2_test_start true`, `start_lane_no 1|2|3`,
  `ros2 param set /obstacle_node m7_trigger_fallback_mm 0.0` → 차를 앞범퍼가 섬 앞 꼭짓점 m2_start_gap + 0.3 m 앞에 놓고
  `/mission/set_state M7_OBSTACLE` (켜지는 자리 = 시작선 + 0, set_state는 시작선 30 cm 앞으로 잡음).
- 안전 정지 범위: 각도가 아니라 차체 폭(±12 cm + 1.5~4 cm) 직사각형. 진행 방향 차체 바로 앞(앞범퍼 -2 ~ +4 cm + 제동 거리)만.
  옆 물체는 아무리 가까워도 차체 폭 밖이면 안 멈춤.
