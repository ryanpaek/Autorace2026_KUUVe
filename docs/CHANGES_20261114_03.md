# 11/14 (1114_03 데이터·영상 대조 분석 및 4대 주행 개선)

`1114_03_data` 및 `1114_03_video` rosbag2 로그 대조 분석 결과를 바탕으로 4가지 핵심 주행 문제를 해결했습니다.

## 1. 3차선 구간(M7) 및 일반 구간 노란 실선 이탈 방지 강화 (`autorace_lane`, `limo_obstacle_avoid`)
- **원인 (1114_03 로그 107.0s~114.2s)**:
  - M7 3차선 구간에서 차가 왼쪽 1차선 바깥 경계인 노란 실선(`line_left: yellow, dashed=False`) 쪽으로 밀릴 때(`offset_mm: +36 -> -117 -> -159mm`), 오른쪽 흰 점선이 시야에서 사라지자(`status='L'`) `lane_id`가 `None`이 되고 Pure Pursuit만으로는 노란 실선 이탈을 막지 못함.
  - `limo_obstacle_avoid`의 `_edge_danger` 또한 오도메트리 `y` 기준(`edge_from: 0.85`)만 보아 오도메트리 누적 오차가 있을 때 늦게 반응함.
- **해결**:
  - `lane_core.py`:
    - `yellow_solid_guard` 파라미터 추가(`yellow_guard_margin_mm: 200.0`, `yellow_guard_hard_mm: 140.0`, `yellow_guard_gain: 2.0`).
    - 왼쪽 또는 오른쪽 차선이 노란 실선(`color == 'yellow'` & `not dashed`)으로 분류되고 차 중심과의 횡거리가 `200mm` 안으로 가까워지면 안쪽으로 강하게 조향(`yellow_guard: 'L'|'R'`), `140mm` 이내 접근 시 변화율 제한을 무시하고 즉시 최대 조향(`±kappa_max`) 명령.
    - 3차선(`lane_color == 'both'`)에서 한쪽 선만 보여도 노란 실선이면 바깥 차로(`L` -> `lane_id = +1`, `R` -> `lane_id = -1`)로 즉시 인식.
  - `avoid_core.py` & `avoid_params.yaml`:
    - `edge_from: 0.85 -> 0.70`, `edge_margin: 0.03 -> 0.05`, `edge_look: 0.30 -> 0.35`로 노란 실선 보호 여유 확대.
    - `_cam_yellow_guard()` 추가: 카메라 `/lane/status`에서 `yellow_guard` 또는 노란 실선 근접(`yellow_cam_offset_mm: 70.0`)이 감지되면 오도메트리 추정과 무관하게 즉시 안쪽으로 최대 조향.

## 2. 갈림길 구간(M2) ~ 라바콘 진입 직전까지 차선 인식 메인 유지 (`autorace_mission`, `params.yaml`)
- **원인 (1114_03 로그 160.2s~183.2s)**:
  - `params.yaml`의 `m8_corner_k_gain: 1.15` 설정으로 인해 M2 합류 뒤 코너에서 안쪽 노란 선을 밟은 뒤 출구(175s)에서 차선을 이탈함.
  - 또한 `cones_enter_cone_mm: 500.0`으로 인해 라바콘 사이로 차가 들어오기 한참 전(50cm 앞)에 `obstacle` 모드로 조기 전환됨.
- **해결**:
  - `fsm.py` & `params.yaml`:
    - `cones_enter_cone_mm`을 `500.0 -> 150.0`으로 축소하여 차량 앞부분이 실제로 라바콘 사이 통로 직전(15cm 이내)에 들어오기 전까지는 차선 인식(`source='lane'`)이 메인으로 주행을 유지하도록 변경.
    - `params.yaml`의 `m8_corner_k_gain`을 `1.15 -> 1.0`으로 맞춰 코너 및 출구 차선 이탈 방지.

## 3. 모든 정지선 5cm(50mm) 앞 정지 (`autorace_mission`, `params.yaml`)
- **원인 (1114_03 로그 77.6s M3, 227.3s M1)**:
  - `stop_target_mm`이 `fsm.py` 기본값 `0.0`, `params.yaml` `30.0`(3cm)으로 되어 있어 실제 제동 후 정지선에 너무 타이트하게(`rem_mm = 28mm`) 멈춤.
- **해결**:
  - `fsm.py`(`DEFAULT_PARAMS`) 및 `params.yaml`의 `stop_target_mm`을 모두 `50.0`(5cm)으로 상향 조정.

## 4. M7·M4 기억후진 시 잘못 들었던 조향의 반대 방향 10% 조향 (`limo_obstacle_avoid`, `autorace_mission`)
- **원인 (1114_03 로그 97.3s~99.6s M7, 257.9s~264.4s M4)**:
  - M7 `trail` 기억후진 시 들어올 때 꺾었던 조향 방향 그대로(`k_rev` 부호 동일) 후진하여 옆 차로로 빠져나갈 회전 공간이 부족했음.
  - M4 `BACK` 후진 시 `back_kappa: 0.0`(직진 후진)으로만 물러나 다시 `TURN`할 때 같은 궤적으로 반복 진입함.
- **해결**:
  - `avoid_core.py` & `avoid_params.yaml`:
    - 전진 시 조향 곡률(`last_fwd_k`, `trail_k`)을 기록하고, `_rollback_step`에서 `k = -rollback_reverse_scale * k_fwd` (`rollback_reverse_scale: 0.10`)를 적용하여 잘못 들었던 길로 갈 때 꺾었던 바퀴 방향의 **반대 방향으로 10% 크기**로 조향하며 후진.
  - `parking_node.py` & `params.yaml`:
    - 전진 진입 시 조향 곡률(`last_fwd_k`)을 기억하고, `BACK` 후진 시 `k_back = -back_reverse_scale * last_fwd_k` (`back_reverse_scale: 0.10`)를 적용하여 반대 방향 10% 조향 후진으로 진입 공간 확보.
