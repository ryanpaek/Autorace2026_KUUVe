## 동작

```
① WAIT_LINE  차선 노드 명령 그대로 넘기며 흰 선 기다림 (FSM은 신호등 직후부터 M4라서)
│
├─② FOLLOW   흰 선 뒤: 차로 중심에서 왼쪽 50mm(왼쪽 차선과 약 8cm)로 차선 추종 (/lane/config target_offset_mm)
│   └─③ 라이다로 오른쪽 리모 두 대 "짝" 찾기 (같은 줄, 사이 1040±150mm) → 중점 = 목표 칸 가운데
│       └─ 중점이 앞바퀴보다 320mm 앞 → PAUSE (1초)
│
├─④ TURN     오른쪽 최대 조향 → 87° 돌면 바퀴 펴기
│   └─ 꺾은 뒤 양옆 리모 옆면으로 칸 가운데 선 → 차체 중심이 칸 가운데에 오면 멈춤
│
├─⑤ CHECK    네 모서리가 칸 선에서 2.5cm 안쪽? (옆·앞뒤)
│   └─ 아니면 재정렬: 바퀴 똑바로 450mm 후진(PULLOUT) → 칸 가운데 선을 pure pursuit로 따라 진입(ENTER). 최대 2번
│
└─⑥ DONE     /parking/state done=true → FSM이 다음으로
```

## 왜 이렇게 했나

| # | 처음 계획/문제 | 바꾼 것 | 근거 |
| --- | --- | --- | --- |
| ① | 리모 한 대가 앞바퀴 옆에 오면 꺾기 | 두 대의 **중점**으로 꺾는 시점을 정함 | 한 대 기준은 약 20cm 일러서 0점. 중점은 칸 가운데 그 자체 |
| ② | 엉뚱한 물체를 리모로 착각 | 짝 = 같은 줄 + 사이 1040±150mm일 때만 | 칸 1개(520)·3개 간격과 안 헷갈림 |
| ③ | 짝으로 멈출 깊이까지 정하면 너무 일찍 멈춤 | 깊이는 꺾은 뒤 보이는 **양옆 옆면**으로 | 차선에서 보면 리모 끝면만 보여 깊이가 80~170mm 얕게 나옴 (시뮬레이션) |
| ④ | 늦게 꺾으면 옆 칸 쪽으로 들어가 갇힘 | 바퀴 편 뒤 막히면 짝으로 기억한 선으로 재정렬 | 40cm 늦게 꺾어도 15점 |
| ⑤ | 5cm 후진 → 다시 꺾기 반복 | 재정렬(나갔다 다시 들어오기) | 후진+꺾기는 방향만 바꾸고 옆으로 밀린 건 못 고침 |
| ⑥ | 재정렬 후진 중 꺾으면 옆 리모와 충돌 | 후진은 바퀴 똑바로 (`pullout_steer: false`) | 꺾고 후진하면 앞이 옆으로 휘둘림 |
| ⑦ | 최대 조향 명령 | 곡률 −3.0 (1/m) | 브리지가 최대 0.40rad로 자름. 축거 0.2든 0.222든 최대 조향 |

## 실차 시험 순서

비상 정지: `ros2 topic pub --once /mission/estop std_msgs/msg/Bool "{data: true}"`

1. **줄자로 재서 `params.yaml`에** — `front_axle_from_lidar_mm`(라이다가 앞바퀴 축보다 앞이면 −), `front_bumper_from_axle_mm`,
   `body_center_from_rear_mm`(차 길이/2 − 뒷바퀴 축→뒤범퍼), `target_offset_mm`(차로 안쪽 폭/2 − 80 − 110)
2. **라이다 확인 (차 안 움직임)** — `python3 tools/parking_scan_check.py -47` (숫자 = 1번 값)
   - 정면 50cm 물체 → 0° 근처인지 (`laser_yaw`)
   - 흰 선 앞 차로에서 정차 리모 1·3번 → "짝: 있음", 4·6번 → "짝: 있음", 주차 표지판 추가해도 그대로인지
   - **짝이 안 잡히면 여기서 멈춤** (라이다 높이·덩어리 기준 문제)
3. **`enabled: true`로 바꾸고 바퀴 띄우고** — `ros2 launch autorace_bringup autorace.launch.py use_detector:=false`
   (WAIT_START라 안 움직임) → `ros2 topic echo /parking/state` →
   `ros2 topic pub --once /mission/set_state std_msgs/msg/String "{data: M4_PARKING}"` → 오류 없이 `"phase": "WAIT_LINE"`
   (`start_state:=M4_PARKING`으로 바로 켜면 켜자마자 움직이니 쓰지 말 것)
4. **바닥** — 흰 선 약 70cm 앞 차로 가운데에서 3번처럼 넘기기. 1·3 다섯 번, 4·6 다섯 번. 녹화:
   `ros2 bag record -o park_13_1 /scan /odom /imu /cmd_vel /limo/ack_cmd /parking/cmd_vel /parking/state /mission/state /lane/status /lane/config /lane/cmd_vel`
   (`scripts/record_bag.sh`에는 `/parking/*`이 없음)

### 11/10 추가 ②: 재정렬 후진을 "똑바로 빼다가 꺾으며"로

윤서 요청: 후진도 실제 주차처럼 꺾으면서. 처음부터 꺾으면 앞이 옆으로 휘둘려 차 옆면이 1번 리모 모서리에 **1mm**까지 붙음 (20cm 일찍 꺾은 경우, 0점).
→ 사람이 빼듯이 **앞범퍼가 옆 리모 끝 + 15cm(`pullout_clear_mm`)를 지날 때까지 똑바로, 그 뒤 칸 가운데 선을 따라 꺾으며** 후진. 총 `pullout_mm` 450 → 650.

| 여유 / 후진 | 7가지 중 15점 | 평균 꺾은 후진 | 왼쪽 차선 |
| --- | --- | --- | --- |
| 5cm / 45cm | 6 (20cm 일찍 0점) | 75mm | OK |
| **15cm / 65cm (기본)** | **7** | **140mm** | **OK** |
| 15cm / 75cm | 7 | 240mm | 넘음 |

다섯 대 12가지는 그대로 15점 12개, 충돌 0, `pytest` 19개 통과. 그림: `docs/parking_reverse_20261110.pdf`.
`pullout_steer: false`면 예전처럼 늘 똑바로 후진.

**아직 남은 위험:** 꺾는 도중(TURN)에는 앞만 보고 옆은 안 봄. 20cm 일찍 꺾으면 TURN 중 1번 리모까지 16mm, 40cm 늦게면 3번까지 34mm (센서 오차 없는 시뮬레이션).

### 11/10 추가 ③: 1·3번 가로선 × 5번 세로선 교점 + 옆 감시 + 끝 정렬

윤서 아이디어: 1·3번(또는 4·6번)으로 가로선, 5번으로 2번 칸 세로선을 구해 교점을 목표로, 회전반경을 고려해 세로선을 따라 들어간다.

| 바꾼 것 | 내용 | 근거 (다섯 대 + 시야 ±105도 시뮬레이션) |
| --- | --- | --- |
| 5번 세로선 (`follow_col5`) | 꺾은 뒤(70도~) 정면 5번 리모 앞면의 좌우 양 끝 가운데 = 2번 칸 세로 가운데선. 그 선을 pure pursuit로 따라감 | 5번은 들어갈 때 정면이라 1번에 안 가림(차선 따라올 땐 가림 → 그때는 안 씀). 측정 오차 1cm 안. 라이다 위치 ±5cm 틀려도 끝 옆 위치 0.3/3.0cm (예전 4.0/6.5cm) |
| 옆 감시 (`side_guard_mm` 50) | 꺾는 중·들어가는 중 리모(지금 보이는 점 + 기억한 위치)까지 5cm보다 가까우면 멈추고 재정렬 | 20cm 일찍 꺾으면 1번 리모까지 1.6cm → 5.3cm. 1번 모서리는 시야 뒤(−122도)라 기억한 위치가 필요 |
| 끝 정렬 (`final_head_tol_deg` 4, `final_lat_tol_mm` 30) | 네 모서리가 칸 안이어도 방향·옆이 넘으면 한 번 더 재정렬. 횟수를 다 쓰면 칸 안이면 그대로 끝 | 끝 방향 평균 7.3° → 4.3°, 옆 평균 4.3 → 1.9cm |
| 짝 보정 | 앞뒤 위치 = 점들의 양 끝 가운데 (`clusters_pair`), 칸 방향 = 차선 추종 중 차 방향 (`pair_dir_from_heading`) | 평균점은 약 6cm 쏠림, 두 리모 잇는 방향은 약 6도 기움 |
| 칸 가운데 선 합치기 (`_cell`) | 옆 위치·방향 = 짝(→ 5번이 보이면 5번), 깊이 = 1·3번 옆면 | 꺾은 뒤 옆면만 쓰면 1번이 반쯤 시야 밖이라 옆으로 약 6cm 틀어짐 |

12가지 조건 요약: 15점 12/12 그대로, 리모 최소 거리 1.6 → 5.3cm, 시간 평균 22 → 33초 (재정렬이 늘어서). 그림: `docs/parking_col5_20261110.pdf`.
`pytest` 20개 통과 (5번 세로선 시험 추가). 노드 입력에 `points`, `clusters_pair`, `clusters_box` 추가 (없으면 예전처럼 동작).

**한계:** 옆 1~3cm·방향 3~4° 아래로는 잘 안 줄어듦 (칸 여유가 한쪽 14cm라 애커만 차가 더 고칠 공간이 없음). 5번 리모가 칸 안에서 비켜 서 있으면 그만큼 따라감.

## 11/11 ⑥ 실차 결과 반영: 재정렬 후진 65→50cm, 꺾기 전 정지 1→0.3초 (params만)

- 실차 2회 (1·3 리모 크기 상자, 5 노트북): 둘 다 만점 기준. 그런데 재정렬 후진(PULLOUT 650mm) 때 왼쪽 노란 선을 밟음.
- 시뮬레이션 (`docs/parking_pullout_20261111.pdf`, 흔들림 12가지): 65cm 노란 선 −0.8cm(밟음), **50cm +9.9cm**, 40cm +19.3cm. 모두 12/12 15점.
  40cm는 꺾으며 후진하는 구간(앞범퍼가 옆 리모를 지난 뒤)이 없어져 끝 방향 최대 17°라 50cm 선택.
- `pause_sec` 1.0 → 0.3: 멈춘 뒤 바로 꺾기 (캡틴 요청). 정지 중엔 Twist로 조향을 못 보내서(속도 0 → 조향 0, 브리지도 0.02m/s 미만 조향 0) 바퀴는 출발과 함께 꺾임. 0.18m/s 제동 약 0.26초.
- 한계: 노란 선 위치는 차로 안쪽 폭 48cm 가정. 시뮬레이션은 즉시 정지라 pause_sec 효과는 실차로 확인.
