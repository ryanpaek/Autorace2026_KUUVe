## 2. 갈림길 표지판 앞에서 서 버림 (시험주행 2번)
멈출 수 있던 조건 (모두 M7_OBSTACLE 상태 안, 회피 노드 `m7_replay_core.py`):
1. 섬 앞 표지판 막대가 라이다에 '가운데 차로 장애물'로 잡힘 -> M2 녹화 길 검사(`m2_hit`)에 걸려 M2 시작 미룸 -> 앞 장애물 540 mm에서 차로 고르기 실패 -> '앞 막힘 -> 정지하고 기다림' (`no_reverse: true`라 물러나지도 않음)
2. M2 시작 자리 + 40 cm(`m2_late_max`)를 지나 가운데 차로에 있으면 M2 녹화 못 씀 -> 섬 앞 15 cm에서 '섬 앞 가운데 차로: 옮길 곳 없음 -> 정지'
3. 재생 중 차체 1.5 cm + 제동 거리 안에 점 -> 안전 정지, 2초 뒤 재생 포기 (이건 실제로 닿기 직전이라 유지)

- `m2_backup`: 1·2번 상황에서 M2 녹화 시작 자리에서는 길이 비면 거기까지 후진 -> 녹화대로 갈림길. 로그 'M2 녹화 시작 자리까지 ... 후진'
