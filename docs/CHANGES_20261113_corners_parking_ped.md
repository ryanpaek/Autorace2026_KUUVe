# 11/13 실차(1113_03, 최신 코드) 뒤 수정: 코너 두 곳 · 보행자 표지 · 주차 정중앙

## 1. 코너 두 곳에서 안쪽(노란) 선 밟음
| 코너 | 실차 기록 | 원인 | 수정 |
|---|---|---|---|
| 갈림길 뒤 (좌하단, 142~151초) | 코너 내내 차선 NONE, 미리 넣은 코너 곡률로만 돎 | 곡률 배율 1.15 = 반지름 0.56m, 차로(0.64m)보다 작게 돎 | `m8_corner_k_gain` 1.15 -> 1.0 |
| 라바콘 뒤 (좌상단 -> M1, 176~181초) | 0.3 m/s 보통 차선, 코너 전 4초 동안 차로 중심에서 21~44cm 안쪽, 조향 약함 | 이 코너만 코너 미리보기가 없었음 | M8에서 넘어오면 IMU 코너 미리보기 + 0.2 m/s + 안쪽 선 모드 (다른 두 코너와 같은 방식) |
- 두 코너 모두 차선이 보일 때 바깥쪽으로 3cm (`corner_outward_mm`)
- 라바콘 뒤 코너는 라바콘 세로 직선 방향 기준으로 85° 돌면 끝 (라바콘 끝에서 이미 조금 돌았어도 더 돌지 않음)
- `track_route.yaml`: `m1_corner_start` (코너 시작 위치, 도면 720,4200)

## 2. 보행자 표지: M6에서 미리 받기
- 실차: 지그재그 끝 무렵 17번 인식(최대 0.93) -> M6은 표지를 안 받아 다 버림 -> M3는 도면 위치로만 정지
- `class_commands.MODE_CLASSES['M6_ZIGZAG'] = ('pedestrian',)`, FSM은 M6에서 확정된 보행자 표지를 기억해 M3 시작 때 바로 정지 준비
- M6 안에서 멈추게 하지는 않음 (기억만)

## 3. 주차
| 항목 | 예전 | 지금 (`params.yaml`) |
|---|---|---|
| 앞 막힘 거리 `front_stop_mm` | 60 | **150** |
| 막혔을 때 후진 `back_mm` | 50 | **150** |
| 전진 <-> 후진 바꿀 때 멈춤 `switch_pause_sec` | 없음 | **0.5초** |
| 옆 2cm 감시에 걸리면 | 그 자리에서 GUARD_STOP으로 끝 | **15cm 후진 뒤 다시** (3번까지, `guard_back`) |
| 양옆 리모 정중앙 | 확인 안 함 (`max_realign: 0`이면 바로 PARKED) | **라이다 점으로 왼쪽·오른쪽 리모 안쪽 면 사이 가운데를 재서**, 15mm 넘게 벗어났으면 45cm 빠졌다가 그 정중앙 선을 따라 다시 (2번까지, `center_check`) |

- 정중앙 = 앞바퀴 앞 0~170, 230~420mm 띠에서 왼쪽 물체 안쪽 면과 오른쪽 물체 안쪽 면의 가운데 (`corridor_mid`).
  1·3번 사이 통로 폭 약 820mm (칸 두 개 1040 - 리모 220)일 때만 믿음
- 시뮬레이션 (5대 배치, 시작 위치 3 x 꺾는 시점 3 x 시야 2 = 18개): 네 모서리·무충돌 18/18 그대로, 끝 옆 오차 평균 19 -> **8mm**, 최대 35 -> **13mm**
- 꺾는 시점을 일부러 틀리게 (15개): 네 모서리·무충돌 12/15 -> **15/15**, 옆 오차 최대 95 -> 30mm대 (하나 70mm)
- 대가: 다시 맞추면 주차 시간 약 16초 -> 26~37초
