# 11/19 M7: 라이다 튐 후진 막기 + 막혔을 때 다른 길 찾기 (+ M2 갈림길 방향 메커니즘 분석)

대상: `src/limo_obstacle_avoid/limo_obstacle_avoid/m7_replay_core.py` (기본 M7 = `m7_impl:=replay`, `m7_replay_node`).
예전 `avoid_core.py`(legacy)는 안 바꿈.

## 1. 앞에 장애물이 없는데 후진 (라이다 점 튐)

### 원인
- 재생 노드 CRUISE는 **스캔 한 번**으로 차로별 '가장 가까운 장애물'(`_lane_obstacles`: 차로 ±18 cm 안, 10 cm 안 3점)을 정했다.
- 그 값이 46 cm(`backup_if_mm`)보다 가까우면 **그 틱에 바로** `BACKUP`(후진). 점 3개만 한 스캔 튀어도 후진.
- `backup_when_blocked`(지금 자세로 녹화 경로가 닿음), 출구 쪽 후진(`pref_needs_backup`), M2 시작 자리 후진(`m2_backup`)도
  이번 스캔 라이다 점(`self.pts`) 한 번으로 정했다.
- M7 안 후진은 이 `BACKUP` 상태에서만 나옴 (녹화 파일 `m7_left/right.csv`는 전진 구간만).

### 고침
- `obs_confirm_frames: 3`, `obs_confirm_tol: 0.10`: 차로 장애물 앞면은 **연속 3스캔 동안 같은 자리(차로 좌표 ±10 cm)**에 있어야 씀.
  차로 좌표(odom+IMU)로 비교하므로 차가 움직여도 서 있는 장애물은 같은 자리. 자리가 매번 다른 점은 3스캔 연속이어도 버림.
  트리거·후진·차로 고르기 순위·미리 계산(plan) 모두 확정된 값 사용.
- 진짜 장애물은 2.5 m 앞부터 계속 보이므로 트리거 거리에 왔을 때 이미 확정 → **트리거가 늦어지지 않음**.
- `reverse_confirm_frames: 3`: 라이다 점으로 정하는 후진(지금 자세로 막힘·출구 쪽·M2 시작 자리)은 그 판단이 연속 3스캔이어야.
  그동안은 **정지만** (반대쪽으로 바로 가지 않음).
- 차체 바로 앞 **안전 정지(`_safety`)는 그대로 1스캔** (정지는 안전, 후진은 안 함).
- 카메라 차로 번호로 차로가 통째로 바뀌면 장애물 기록도 같은 만큼 밀어서 확인을 이어감 (빈 스캔 없음).
- 예전으로: `ros2 param set /avoid_node obs_confirm_frames 1`, `reverse_confirm_frames 1`.

### 확인 (시뮬레이션 `tools/m7_replay_sim.py`, 실차 yaml 값, 실제 녹화 경로)
| 조건 | 예전 | 지금 |
|---|---|---|
| 표준 배치 42판, 튐 없음 | 42/42 통과, 후진 0 | 42/42, 후진 0 (같음) |
| 스캔 5%에 차 앞 25~50 cm 점 3~6개 튐 | 42/42 통과, **41판에서 헛후진** (합 2.2 m) | 42/42, **헛후진 0** |
| 스캔 20% 튐 (과장) | - | 42/42, 후진 2판 합 0.09 m (같은 자리 3번 연속 튄 경우) |

## 2. 앞·옆 다 막혔다고 보고 영원히 서 있음 (실제로는 빠질 틈 있음)

### 원인
- 트리거(장애물 540 mm)에서 `choose()`는 옆 차로마다 **녹화 경로 하나를 정해진 자리(장애물 - 540 mm)에 붙여 본 것**만 봄.
- 양쪽 다 닿으면 `no_reverse: true`라 물러나지도 않고 `'앞 막힘 ... 서서 다시 봄'` → 상황이 안 바뀌니 **영원히 정지**.
- 실제로는 몇 cm 더 가거나(옆 차로 장애물이 차 옆을 막 지나는 중) 조금 물러나거나 다른 각으로 꺾으면 빠지는 배치가 있음.
  예: 오른쪽 차로 LIMO가 차 바로 옆 → 그 자리 녹화 경로는 뒤 모서리가 닿지만 5 cm 더 가서 시작하면 3 cm 여유로 통과.

### 고침 (`rescue: true`)
막힘이 연속 3스캔이면 아래 순서로 갈 길을 찾음 (0.5 s마다, 서 있는 동안만):
1. 지금 자리 ~ 20 cm 더 간 자리(5 cm 간격)에서: 녹화 경로 / 만든 S자(25~60°, 반경 0.53 m x 1.2)
2. 1이 다 막히면: 10 cm씩 50 cm까지 물러난 자리에서 같은 길
- 길은 **지금 실제 자세(x, y, 차 방향)**에서 시작해 굴려 봄 (차로와 틀어져 있어도). 녹화 경로는 차로와 5° 안일 때만.
- 차체 + 4 cm(만든 S자) / 3 cm(녹화) 안에 라이다 점 없고, 섬(도면 위치)은 + 8 cm, 도착 뒤 15 cm 더 가도 안 닿아야.
- 출구(A/B)를 알면 출구 쪽 먼저, 모르면 확정 장애물이 더 먼 쪽 먼저. 다 막혔으면 예전처럼 서서 다시 봄.
- 로그: `막힘 -> 다른 길: 5 cm 더 가서 녹화로 차로 -1` / `다른 길도 없음 (...)`. `/avoid/state`에 `n_rescue`, `gaps_raw_mm`.
- 계산은 '앞으로'와 '물러나서'를 다른 틱에 나눔 (가장 느린 틱 약 0.1 s, `/avoid/active` 1초 끊김 감시에 안 걸림).
- 끄기: `ros2 param set /avoid_node rescue false`. 후진만 빼기: `rescue_back false`.

### 확인 (무작위 배치 60개, 3열 x 1~2대, 실차 yaml)
| | 예전 | 지금 |
|---|---|---|
| 부딪힘·섬 침범 없이 끝 | 38/60 | **41/60** (나빠진 판 0) |
| 60초 정지 | 19 | 16 |
- 새로 통과한 3판 최소 간격 3.4~4.6 cm, 섬 침범 0.
- 남은 16판: 12판은 그 자리에서 물리적으로 길이 없음 (일찍 한쪽 바깥 차로를 골라 막다른 차로, 반대쪽 바깥 차로까지 두 칸을
  0.5~0.6 m 틈으로 건너야 함. S자 두 칸은 최소 약 1.3 m 필요) → 원인은 **처음 차로 고르기(가까운 것만 봄)**, 이번 변경 범위 밖.
  4판은 '후진 → 재생 → 안전 정지 → 후진' 반복 (예전과 같은 결과).
- M2 녹화 재생 켠 표준 배치: 예전·지금 모두 42/42 (같음).

## 3. M2 갈림길: 표지를 A로 봤는데 B로 들어감 — 메커니즘 (분석만, 코드 안 바꿈)

방향 정보 흐름: YOLO → FSM 투표 `fork_choice` → m7_link `/fork_direction` → 재생 노드 `exit_pref` → M2 녹화 선택 → 끝난 차로 `m7_exit` → FSM M2.
(`fork_node`도 같은 토픽에 보내지만 `follow_fsm: true`라 FSM 값을 따름)

'확정'되어 그 뒤 표지를 봐도 안 바뀌는 곳:
1. **FSM 투표 한 번 정하면 끝** (`fsm.py` `_remember_fork`): M7 동안 3프레임(early confirm)이면 정하고 그 판 끝까지 안 바뀜.
2. **M2 녹화 선택 시점** (`m7_replay_core` CRUISE 1b): 앞범퍼가 섬 앞 꼭짓점 1.0 m 전(`m2_start_gap`)에 오는 순간
   (지금 차로, 그때 `exit_pref` 또는 기본 `m2_fork_default: A`)로 녹화 하나를 골라 끝까지 재생. 재생 중 표지가 와도 무시.
   시뮬레이션: 표지 B가 그 시점 9 cm 뒤에 도착 → 기본 A 재생 → A로 감.
3. **M2 녹화 길이 막히면 차로 위치가 방향을 정함**: 그 시점 표지 쪽 녹화 길에 물체 → '장애물 먼저' → 일반 회피가
   비어 있는 바깥 차로(표지 반대쪽일 수 있음)로 옮김 → 40 cm(`m2_late_max`) 지나면 M2 녹화 포기 → 그 차로로 끝 → `m7_exit` = 반대쪽.
   시뮬레이션: 표지를 처음부터 알아도 표준 배치 42판 중 9판이 이렇게 반대 갈래로 끝남.
4. **FSM M2는 끝난 차로를 따름** (`fork_follow_m7_exit: true`): 표지와 차로가 다르면 `M2 fork conflict: sign A, car in B lane -> follow lane B`.
   표지를 못 정했으면 `fork_from_m7_exit: true`로 끝난 차로를 그대로 씀.
5. M7 중 양쪽이 다 비면 출구 쪽 차로를 고르지만, 출구를 모르면 '더 멀리 빈 쪽' → 표지 반대쪽 바깥 차로에 있다가 늦게 본 표지를 못 따라감.

실차 로그로 구분하는 법: `[M7 재생] M7 끝 지점 -> M2 갈림길 재생 m2_X-Y.csv (... 갈래 Y: 표지 | 표지 못 봄 -> 기본 A)`,
`M2 녹화 길에 물체 -> 장애물 먼저`, `M2 녹화 ... 없음 -> 예전 방식`, FSM `M2 fork conflict`, `갈림길 X 결정`.
